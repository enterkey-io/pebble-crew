# 0.7.18-preview.1

- Phone pages and overlays share safe areas for the status bar, home indicator
  and keyboard. Settings, Org chart, details and editors keep their close
  controls accessible. Chat and navigation share consistent title labels and
  typography. The connection indicator includes text in both themes.
- Swipe in either direction between the conversation list and the retained chat.
  Reordering a sidebar row cancels its press-and-hold menu.
- Sidebar sections organize rows independently of explicit group chats. Existing
  Crews become sections. Native groups retain their history and participants.
- Enrolled pebbles can create sections, move sidebar rows, start a group chat
  with selected participants and update their own appearance and routines.
  The Main Pebble can manage appearance and routines for other pebbles.

Upgrade the combined plugin using the [tagged installation guide](../AGENT_INSTALL.md).
Activate the host before synchronizing enrolled runtimes. Preserve the sidebar
migration backup. An older release that cannot read the updated sidebar format
is refused before rollback.
