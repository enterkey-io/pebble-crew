# Pebble Crew 0.7.8-preview.15

Voice remembers one saved-key approval across pebbles and restarts. Each pebble
keeps its own voice choice. Keys stay in Hermes's native credential storage;
Pebble Crew stores only the approved source and a fingerprint. Completed key
replacement requests no longer reappear when switching editor tabs.

Role editing now has one optional Instructions field for the job, steps and
limits. Older role text carries over without changing the agent's SOUL or memory.
Title and Description stay in Profile, and reporting stays in Role.

Chat photos open in a borderless full-size viewer. Use the mouse wheel, keyboard
zoom shortcuts, pinch gestures or drag to move around the image.

Verified production desktop and phone flows, native preferences and the final
installed package in disposable infrastructure. Native model checks use a local
synthetic model. Physical-device behavior and an owner's network route require
separate acceptance.

Use the tagged [agent guide](https://github.com/enterkey-io/pebble-crew/blob/v0.7.8-preview.15/docs/AGENT_INSTALL.md)
to update. Preserve owner state, credentials, ports and routes. Publishing this
release does not upgrade an owner's Hermes installation.
