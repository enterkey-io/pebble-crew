# 0.7.8-preview.3

Unsectioned pebbles appear as a plain list below pins. There is no default
Pebbles heading or collapse control, including on older installations that had
collapsed that section. Custom sections remain optional. Choose None in Move to
section to return a pebble to the plain list.

The account menu and Settings → Account now offer Your photo. Upload, replace or
remove a personal photo; the empty state is an account icon. Personal avatars
have no animated shapes. The browser crops and resizes locally, and the owner
service constructs a fresh PNG in the existing login store. Photos stay on the
owner's infrastructure, separate from Hermes profiles. Existing logins need no
migration or new setup.

Validation covers production desktop/iPhone WebKit/Android Chromium journeys,
photo failures and reconnect continuity, real Node owner login/persistence, and
local workerd/D1 with an independent browser decode of noisy/transparent pixels.
Origin, session, body-size and revoked-session checks cover the owner-only route.
Final combined archive acceptance precedes publication.

This includes the pinned tile, agent media, Markdown and conversation restoration
fixes from [preview.2](0.7.8-preview.2.md). Voice remains researched, not implemented.
