# v0.7.10-preview.1

New pebbles can use the existing shared Codex OAuth login on supported Hermes 0.21.7, without copying login tokens or requiring another sign-in. Hermes remains responsible for account selection and token refresh. Hermes 0.21.0 needs a native upgrade for this creation path; its existing API-key and custom-provider paths remain available.

Creation preserves the full reviewed role, including title and Instructions. Every creation attempt records its stage; incomplete profiles stay out of the enrolled roster. A failed or uncertain creation is never replayed automatically.

Management approval cards retain the saved failure reason, remove unavailable approval actions, and offer a read-only status check when a decision cannot be confirmed. Chat and Settings share this handling.

No changes to the owner URL, login, credentials or personas are required. Follow the tagged [agent upgrade guide](https://github.com/enterkey-io/pebble-crew/blob/v0.7.10-preview.1/docs/AGENT_INSTALL.md). Do not retry a historical failed creation blindly: describe the current model grant and request a fresh exact approval. Inspect any existing partial profile first.

Validation uses synthetic credentials and disposable native homes. A provider configuration receipt does not prove live provider access.
