# Pebble Crew 0.7.8-preview.23

Crews now have a selectable manager, shown first with a muted pennant badge.
Their purpose and leadership reach the real Hermes agents without changing
reporting relationships, SOUL, memory or model configuration. The Main Pebble
can manage existing Crew membership, leadership and purpose using the same
ask-first policy as reporting changes.

- Pins remain the large avatar tiles. A normal-sized shortcut can expose a Crew
  member near the top without removing them from their Crew.
- Crew members use smaller, indented rows. Crews can share the unlabelled list
  or custom sections; there is no mandatory Crews section.
- Agent-to-agent messages use separate native profile sessions. Both owner
  chats show a compact link to their shared conversation. Peer messages no
  longer enter the recipient's owner chat as human messages. Existing history
  is not rewritten. This requires the supported Hermes 0.21.7 build; older
  Hermes without native bot authorship refuses peer delivery safely.
- Page titles follow conversations, project boards, Settings tabs, the org
  chart and editors. Titles restore when editors close and track saved renames.

This release uses runtime contract v3 and sidebar schema 2. Activate the host
first, synchronize runtimes while native work is stopped, then restart the
supervised service and stopped profile processes. Runtime synchronization now
also restores the default profile's plugin and matching web assets, with a
private rollback backup. Incomplete runtime updates refuse chat admission.
Unsafe downgrades that would erase shortcuts are refused.

Use the [tagged upgrade guide](https://github.com/enterkey-io/pebble-crew/blob/v0.7.8-preview.23/docs/AGENT_INSTALL.md).
Preserve the existing login, private state, credentials, ports, supervisor and
HTTPS route. No new setup link or pairing is needed. Installation and update
verification do not run owner models. Publishing this release does not upgrade
an owner's installation.
