# Pebble Crew 0.7.8-preview.18

Chat and Tasks now share the app. Create a **New project board** or **New task**
from the global + menu in either area. Each project board links one native Hermes
Project to its own Kanban board; General tasks holds small, unfiled work. Chat
drafts and reading positions stay in place when switching areas.

Task cards show native status, priority and assignee. Open a card to edit its
instructions or add a formatted comment, and read native results and dependencies.
New tasks enter Triage: saving does not start an agent. Worker dispatch, execution
transitions and review controls remain in the later execution phase. Routines stay
with their agents and are created through chat.

Agents receive the discoverable `workspace_work` tool and `bot-web:manage-work`
skill after runtime synchronization and process restart. Explicit project/board
scope, stable save identities and conflict handling protect concurrent edits and
interrupted requests. Native projects, tasks and comments remain in Hermes; private
catalog bindings and recovery receipts stay on that same host.

Both supported Hermes builds support project/task creation, reading and comments.
Task-detail editing requires 0.21.7; those fields are read-only on 0.21.0. Imported
boards with missing or conflicting native project links remain readable and need
their mapping repaired in Hermes before editing.

Also fixes mobile Requests layout, replaces the requests text counter with an
inbox indicator, closes org cards after confirmed saves and clarifies Main Pebble
management controls.

Verified the production desktop, iPhone and Android flows, native persistence and
deferred agent tools on both pinned Hermes builds using disposable homes and a
deterministic local model. The final archive also passes installation, upgrade
and rollback acceptance. These checks do not exercise an owner's network route or
physical phone.

Update using the tagged [agent guide](https://github.com/enterkey-io/pebble-crew/blob/v0.7.8-preview.18/docs/AGENT_INSTALL.md).
Preserve all owner state, including `work.sqlite`, native projects/tasks, account,
credentials, ports and routes. Activate the host first, synchronize native runtime
copies, then restart and verify the existing HTTPS URL. Publishing this release
does not upgrade an owner's Hermes installation.
