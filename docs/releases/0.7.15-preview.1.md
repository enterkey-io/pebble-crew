# 0.7.15-preview.1

Typing updates the composer without rebuilding the conversation and sidebar.
Historical message controls retain their rendered state while new text streams;
date and time formatting uses shared formatters.

Background request discovery no longer replaces the composer with an approval
error. Brief failures preserve drafts, focus and known pending requests. Repeated
failures show a quiet retry notice. Genuine pending decisions and unreadable
request records retain their protected review surfaces.

New approvals remain available when the separate recent-receipt read fails.
Request refreshes wait for an existing scan instead of adding overlapping scans,
and unchanged results keep their current state.

The browser suite compares typing work with short and long conversations using
five interleaved pairs. The check fails against the previous release. Production
browser profiles and desktop, phone and native chat checks cover the changed
paths; synthetic measurements do not establish every device's performance.
