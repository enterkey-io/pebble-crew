# 0.7.20-preview.1

- The loading screen shows the animated pebble without a role badge. It uses
  the default Iris pebble until the Main Pebble’s saved appearance is available.
- Three pinned pebbles fit at the minimum desktop sidebar width. Photo avatars
  use circular thumbnails, and reopening a section reuses loaded photos.
- A pebble without an active Bot Chat shows an error that names the pebble and
  preserves the current conversation and draft.

Upgrade the combined plugin using the [installation guide](../AGENT_INSTALL.md).
