# Pebble Crew 0.7.8-preview.20

Removes the Main Pebble management switch. The current Main Pebble can always
manage reporting and Instructions. It asks before unsolicited changes; a clear
owner request already authorizes its change. Server checks still enforce current
identity, reporting cycles, stable targets and revisions.

The org view is now a connected chart with fixed-size shared cards, separate
unattached trees, pan/zoom, Fit chart and Center Main Pebble. Keyboard focus brings
offscreen cards into view, phones support pinch and pan, and saving a reporting
change preserves the edited card’s screen position.

Task creation and editing share title-first fields and a Status selector. Cards
use grab cursors, a fully visible inset drop target and consistent board icons.
Unrelated native text edits and normal queue promotion no longer create false
movement conflicts. Concurrent reassignment and completed work remain protected.

Activity exposes native Hermes events, comments and worker reports with authors
and timestamps. Workers receive progress/result-reporting guidance. Outcomes from
assigned work queued through Pebble Crew go to the existing Bot Chat, with durable
receipt and identity checks. Unconfirmed deliveries are not automatically replayed.
Owner-pausing idle work never promotes it into a runnable state in between writes.

Slash-command suggestions, attachments and the composer share one width constraint,
keeping the selector attached to the chat bar as the viewport or details panel changes.

Primary buttons and unread/review indicators share a restrained terracotta accent.
Light/dark foregrounds are chosen for contrast; ordinary surfaces and focus stay
neutral. Agent colors remain independent.

Use the tagged [agent guide](https://github.com/enterkey-io/pebble-crew/blob/v0.7.8-preview.20/docs/AGENT_INSTALL.md).
Preserve owner data, credentials, ports and HTTPS routes. Install/update checks do
not run owner models. Publication does not upgrade an owner's installation.
