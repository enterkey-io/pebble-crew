# Pebble Crew 0.7.8-preview.19

Fixes the competing UI styling paths across Settings, Add/Edit Pebble and Tasks.
Shared components now own dialog sizing, destructive buttons, confirmations,
toggles and disclosure motion. The old overrides and duplicate discard dialogs
are removed, with CI checks that reject those patterns. Pinned avatars and title
labels retain their intended sizing; the upper-left wordmark uses the website’s
locally bundled Caprasimo font.

Tasks have content-sized editors, a visible Chat/Tasks toggle, clear creation
results and compact discard confirmation. Cancel closes unchanged tasks directly.
Boards use Description and tasks use Details. Unsaved task edits must be saved
before changing status, and late responses cannot move a task into another board.

Move cards by dragging on desktop, through their Move to menu or with the task’s
Status control. Moving assigned work to To do queues it through Hermes’s native
dispatcher, respecting dependencies and execution policy. New tasks stay in Triage
until queued. Comment @ completion notifies the enrolled agent in its existing
Bot Chat. An uncertain notification is not silently sent again. Task-detail
editing still requires Hermes 0.21.7; those fields are read-only on 0.21.0.

Browser verification covers desktop, iPhone WebKit and Android Chromium, including
settled screenshot review. Native acceptance uses disposable homes on both pinned
Hermes builds and a deterministic local model for mention delivery. Queue checks
substitute the worker spawn boundary while exercising native claims and completion.
Install and update checks do not run owner models or change owner personas.

Use the tagged [agent guide](https://github.com/enterkey-io/pebble-crew/blob/v0.7.8-preview.19/docs/AGENT_INSTALL.md).
Preserve owner state, credentials, ports and routes. Activate the host first,
synchronize runtime copies while native agents are idle, then restart through the
existing supervisor and verify the existing HTTPS URL. Publishing this release
does not upgrade an owner’s Hermes installation.
