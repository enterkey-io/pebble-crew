# 0.7.8-preview.2

Pinned pebbles place the avatar in the upper third of the tile, with the name and
role label centered below it. Longer role labels wrap to two lines. The action
menu sits at the corner without reserving a spacer row above the avatar.

Saved agent photos and files now render through authenticated native reads in
direct Bot Chats. Standard Markdown and standalone `MEDIA:` references work from
the current profile's generated/cache directories. Raster images display inline;
other files download on request. Files are limited to 10 MiB. External images
remain explicit links. See [media behavior and limits](../AGENT_MEDIA.md).

Code preserves indentation and horizontal scrolling, shows its language and has
an icon copy action. Quotes, lists, task lists and tables have consistent spacing;
wide tables scroll without squeezing headings into single-letter columns. Reload
restores the selected pebble or room by stable identity behind the quiet progress
view. A removed or replaced identity falls back to the Main Pebble.

This update adds native media capability and agent output guidance; update the
combined plugin using the tagged guide. It preserves owner login, profiles and
configuration. Preview suffixes identify incremental fixes within 0.7.8.

Validation includes source/unit checks, production desktop/iPhone WebKit/Android
Chromium journeys, settled screenshot review, actual native owner-browser media
delivery and isolated media reads on both supported Hermes snapshots. The native
media checks assert zero model turns; the owner-browser journey uses only its
disposable local synthetic model. Final archive acceptance precedes publication.

[Voice chat research](../VOICE_FEASIBILITY.md) recommends reusing owner-side Hermes
STT/TTS. Voice is planned; this release does not add microphone capture.
