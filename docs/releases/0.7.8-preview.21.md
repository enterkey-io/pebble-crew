# Pebble Crew 0.7.8-preview.21

Restores neutral action colors and circular composer controls. Unread messages
use a blue pulsing dot at the far-right row edge. Pinned pebbles show it in the
lower-right avatar badge position, replacing the Main Pebble star until read.
Reduced-motion settings keep the dot static.

Org cards respond across their full surface. The whole canvas supports grabbing
and ordinary wheel zoom. Handle fields use one shared input boundary.

Task boards use neutral inset lanes, padded drop targets and persistent ordering
within columns. Reordering does not change native priority or trigger another
run. Activity keeps its header fixed and its comment form reachable. Closing task
creation restores board focus without triggering Search.

Native approvals and agent-management proposals appear as conversation cards.
Pending approvals from another pebble send one notification to the Main Pebble's
existing Bot Chat. Owner approval and exact-request checks remain required.
Native clarify prompts use structured question cards; secure entry continues to
use Hermes's supported native secret mechanism, outside chat text.

Photo wheel, keyboard and toolbar zoom stay centered; drag/pinch remain available.

Use the tagged [agent guide](https://github.com/enterkey-io/pebble-crew/blob/v0.7.8-preview.21/docs/AGENT_INSTALL.md).
Preserve owner data, credentials, ports and HTTPS routes. Install/update checks
do not run owner models. Publication does not upgrade an owner's installation.
