# Pebble Crew 0.7.8-preview.21

Restores neutral action colors and circular composer controls. Unread messages
use a blue pulsing dot at the far-right row edge. Pinned pebbles show it in the
lower-right avatar badge position, replacing the Main Pebble star until read.
Reduced-motion settings keep the dot static.

The composer uses a soft circular attachment button. Its primary action offers
Voice when empty and changes to Send when typing or attaching a file. The edge
is subtle in both themes. Sidebar role labels use the available row width.

Crews drag as whole blocks and have independent expand/collapse chevrons. Click
its name for Crew chat. Sidebar actions use right-click, touch press-and-hold or
Shift+F10, without overflow buttons. Move menus include New crew/New section;
creation carries the selected pebble. The dark rail is darker than the chat and
the right details panel matches the chat background in both themes.

Org cards respond across their full surface. The whole canvas supports grabbing
and ordinary wheel zoom. Handle fields use one shared input boundary.

Task boards use neutral inset lanes, padded drop targets and persistent ordering
within columns. Reordering does not change native priority or trigger another
run. Activity keeps its header fixed and its comment form reachable. Closing task
creation restores board focus without triggering Search.

Native approvals and agent-management proposals appear as conversation cards.
Pending approvals from another pebble send one notification to the Main Pebble's
existing Bot Chat. Owner approval and exact-request checks remain required.
Native clarify prompts use structured question cards; secure entry continues to
use Hermes's supported native secret mechanism, outside chat text.

Shared MP4 clips play inline and open in a larger, zoomable viewer with playback,
seeking, mute and download controls. Videos load on request and do not autoplay
on page load. The existing 10 MiB shared-file limit remains. Chat photos have rounded corners. Photo wheel, keyboard and toolbar zoom stay
centered; drag/pinch remain available.

Agents are prompted to consider a fitting reaction before replying. An
acknowledgement that needs no answer can receive only a reaction. Native silence
markers stay out of live and reloaded transcripts; personality files are unchanged.

Crew creation and editing include Description and a member picker. A separate
Group chat action creates an ad hoc conversation without moving pebbles or
changing crew membership. Both chat types suggest member @handles and show each
speaker's small avatar. Crew activity uses crew terminology. Group conversations
have no fixed sidebar heading. Owner and agent reactions work in both chat types
through an owner-local extension over verified native message IDs. Reactions align
with their message side and current group feedback reaches the next native turn.
Group sends retain their bubble through the native receipt and later polling.

Send remains available while a pebble is working. Hermes applies its native
busy-input behavior, normally redirecting the current work; Stop stays separately
available while typing. No queue choice is added. The transcript preserves the
reply before the follow-up and renders the continuation below it. Native row
anchors and correction offsets restore the live turn after reopening.

Slash commands filter locally as you type. Enter runs the selected command once;
model selection still accepts an argument. Native command output appears inside
the conversation using the shared tool component, without sending a model prompt.

Use the tagged [agent guide](https://github.com/enterkey-io/pebble-crew/blob/v0.7.8-preview.21/docs/AGENT_INSTALL.md).
Preserve owner data, credentials, ports and HTTPS routes. Install/update checks
do not run owner models. Publication does not upgrade an owner's installation.
