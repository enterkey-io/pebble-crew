# v0.7.12-preview.1

Crews have a manager and purpose shared with their members. Managers sort first
and use a subtle flag marker. Membership does not rewrite reporting lines or
agent personalities. Group portraits now show up to five actual members, with
smaller static background faces, one animated foreground face and a count for
larger Crews.

**Plans** appears above project boards in Tasks. Plans describe shared goals,
responsible pebbles, parent goals, contributing Crews and linked native project
boards. Each project board also has a focused **Goal** editor. These records stay
in the owner's plugin; native Hermes still owns tasks, history and execution.
The current Main Pebble can maintain the same goals through its actual work tool.
Current Crew purpose and relevant goals reach direct chat, Crew rooms, private
exchanges, live voice and native task workers. Reading goals never grants action
permissions or starts work.

First use and General settings offer optional **Proactive help**. Suggestions
require actual enabled and permitted native calendar/mail read tools. Nothing is
selected automatically. The owner reviews the instructions, schedule and Hermes
timezone before creating native cron jobs. Setup does not run a model or invoke
an external tool. Unconfirmed native creation is never retried as a new job;
its original receipt remains recoverable after closing or reloading.

Returning from another app preserves the settled conversation position. Verified
owner uploads appear as file cards rather than expanded Markdown inside the
owner's bubble. All attached content still reaches Hermes's model and persisted
native history remains unchanged.

The production app is exercised on desktop, iPhone WebKit and Android Chromium.
Native acceptance uses disposable homes on both pinned Hermes builds and a
localhost model. It verifies real deferred tools, native dispatched workers,
actual delivery into the existing Bot Chat, and model-free routine setup followed
by separate deliberate acceptance execution. No owner service, credential or
persona is used in these checks. Browser emulation is not physical-device proof.

Use the tagged [upgrade guide](https://github.com/enterkey-io/pebble-crew/blob/v0.7.12-preview.1/docs/AGENT_INSTALL.md).
Preserve state, existing routines, pending requests, access and the HTTPS route.
Do not create test jobs or run model prompts on an owner's installation.
