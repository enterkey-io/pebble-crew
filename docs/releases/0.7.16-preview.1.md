# 0.7.16-preview.1

Phone navigation uses a full-page conversation list with account and New controls,
horizontal pinned pebbles, larger rows and bottom search. Back and the leading-edge
swipe retain the current chat and draft. Desktop resizing and navigation remain.

The mobile composer uses the full app viewport, larger type and one action. Return
inserts a new line; Send submits. Returning to the app and using Latest messages do
not focus the composer. Outgoing phone bubbles allow 85% width.

Backgrounding suspends transport without tearing down the loaded interface. Warm
resume retains drafts, navigation, pending operations and reading state. Connection
admission can reclaim abandoned same-owner streams at capacity while protecting
active or recently used tabs, polling clients and in-flight operations. iOS can
still discard a document under memory pressure; this release does not bypass that.

Live reply updates render in a narrow transcript subtree and coalesce paints.
Closed reaction menus and hidden-list avatars do less work. A five-pair production
benchmark with 300 historical messages and the same 100-chunk reply reduced median
browser scripting from 629 to 149 ms. Typing-paint ranges overlap. These synthetic
results do not establish physical iPhone temperature or every device's performance.

Question cards align Skip left and Submit right; a single request has no paging
header. Shared dialog actions stay together on phones. Production dark/light
screenshots were reviewed across chat, navigation, Settings, Add/Edit, approvals,
voice, tasks, org, media, documents and menus. Existing-agent group labels now match
their accessible names.

This release preserves existing Crew behavior and owner data. The sections/explicit
groups redesign and optional Tasks visibility setting are separately tracked.

The iOS PWA header and composer respect both native safe areas with a small inner gap. Pending input can be minimized with X to keep chatting, then reopened from its compact pending control. Minimizing never approves or denies a request.
