# 0.7.16-preview.1

The mobile conversation list is a full page with pinned pebbles, an account menu,
New and bottom Search. Back and a leading-edge right swipe in the installed PWA
return to the list while retaining the conversation, draft and scroll position.
Desktop resizing keeps the same conversation and media viewer mounted.

The PWA uses the full phone canvas except when an editable field and reduced
visual viewport indicate an open keyboard. Safe-area space is counted once.
Phone text uses a larger shared scale, and long outgoing bubbles can occupy 85%
of the available width. Short bubbles still fit their text.

Returning from another app leaves the keyboard closed. Page-hide suspends the
live connection instead of permanently closing its owner; returning restores
transport behind the existing interface. This does not prevent iOS from
occasionally discarding an entire browser document. Under connection-capacity
pressure, abandoned streams can be reclaimed for the same principal after a
quiet heartbeat interval; active tabs, other principals and in-flight requests
are preserved.

There is one composer action: Send while composing, Stop during an active turn
when not composing, and Voice when idle without a draft. On touch devices Return
inserts a newline; the Send button submits. Desktop Enter and Shift+Enter keep
their existing behavior.

Questions align Skip left and Submit right. A single pending request has no
redundant paging header; multiple pending requests retain their navigation and
independent forms.

Live reply text updates its transcript surface without invalidating the whole
application shell. Visible token updates are bounded to 30 frames per second.
Closed reaction menus mount their interactive listeners only when opened, and
hidden navigation avatars pause. These changes require physical-device feedback
before claiming the reported phone heat is resolved.

This release does not activate the sections/groups migration or change existing
Crew membership, coordination, reporting, personas or conversations. That
redesign is tracked separately pending the owner's migration choices.

Upgrade through the tagged [installation guide](../AGENT_INSTALL.md), preserving
the existing URL, login, state and enrolled runtimes. Install and update checks
must not send model prompts or reset browser access.
