# 0.7.14-preview.1

Connect native apps from Settings → Devices → Add a device. The combined plugin
creates local QR codes and Mac handoff links. Invitations expire after five
minutes and can be redeemed once. The dialog waits for a real native Hermes
handshake before listing the device.

Each device has an independent persistent grant. Credentials are hashed on the
owner host; revocation rejects existing tickets and closes its open HTTP streams.
The existing owner login and all Hermes profiles remain unchanged.

Requests no longer have a separate Settings page. Pending decisions remain in
chat. Requests from an unavailable pebble remain reviewable in the Main Pebble's
conversation, and completed decisions retain compact receipts.

Live recovery preserves committed replies and user chronology during background
work. The bridge identifies the exact assistant rows belonging to a live turn;
the client no longer discards all later replies after a user anchor. Archived
pre-compaction rows cannot anchor the current turn or reappear as queued input.

Direct-chat tool approvals now offer Allow for this session and Always allow this
action when Hermes permits those scopes. Restricted requests remain one-time
only. Crew-chat tool approvals and agent-management changes retain their native
individual approval requirements.
