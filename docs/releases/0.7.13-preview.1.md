# 0.7.13-preview.1

The updater recognizes the complete 0.7.11 runtime inventory. It preserves
compatibility checks and refuses unknown or incomplete copies. Installed-package
acceptance starts from the exact published 0.7.11 archive with ten enrolled
profiles, then checks activation, runtime sync, restart and rollback.

Native background completion notices appear as compact activity instead of human
messages. The owner display and Search exclude hidden operational input. Native
model history stays unchanged.

Returning to the browser preserves the latest position or the saved reading
position. The unread dot has a 12px inset. Offscreen chat images release their
resources while open viewers retain theirs. Library reads at most three history
pages when it opens, with older pages available through Load more.

The owner's broader slowdown remains under investigation. A bounded Library scan
and released image resources do not prove that the reported regression is fixed.
