# Pebble Crew 0.7.8-preview.22

Approval cards now stay at their original point in the conversation. Later owner
messages and agent replies appear below them, including after reloads and
reconnections. Management requests expose their persisted creation time; existing
records remain compatible.

Resolved management approvals collapse into a compact record showing the action,
agent and outcome. Open the record to inspect its details. Pending, executing and
uncertain requests retain the controls needed to review them safely.

Update the complete plugin, including its web app and integration, using the
[tagged agent guide](https://github.com/enterkey-io/pebble-crew/blob/v0.7.8-preview.22/docs/AGENT_INSTALL.md).
Preserve the existing login, private state, credentials, ports and HTTPS route.
Install/update checks do not run owner models. Publishing this release does not
upgrade an owner's installation.
