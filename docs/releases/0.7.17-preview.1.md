# 0.7.17-preview.1

Settings → General includes a Tasks switch shared by the owner's installation.
When off, Tasks/Plans navigation and creation are hidden and saved strategic goals
are suspended in text, live voice and worker context. Native Kanban and routines
remain available for background work. Boards, tasks, Plans, outcomes and personas
are preserved. Turning Tasks on restores their existing data and starts no work.

Preference writes bind the intended workspace and revision. A lost response is
checked by reading current state; a late receipt cannot replace newer agent
information or update a settings screen that has been left. Open task and goal
drafts survive a preference change from another tab.

Includes the PWA and approval improvements published in 0.7.16-preview.1.
Complete the tagged guide's runtime synchronization/restart so enrolled agents use
the new goal policy. Installation and verification run no owner models or change
owner settings.
